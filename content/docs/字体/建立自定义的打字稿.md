[自动载入 typescriptfile 而不必手动指定](自动载入%20typescriptfile%20而不必手动指定.md)

不同於通過 `\definefont` , `\definedfont` , `\definefontfamily` 等可以直接在當前文稿中定義或直接使用的字體命令，還可以通過在外部文件中定義字體，並在文稿中通過 `\usetypescript` 等命令來調用相關的字體。

要使用 typescriptfile 來定義字體主要依賴以下命令：

- `\usetypesctipt` 調用打字稿中定義好的字體。
- `\usetypescriptfile` 調用外部文件打字稿中定義好的字體。
- `\loadtypescriptfile` 加載外部文件打字稿中定義好的字體。
- `\starttypescriptcollection` 一系列相關的 typescript 合集可以用該命令包裹。
- `\starttypescript` 開始定義 typescript。
- `\definefontsynonym` 定義字體樣式和字體實體之間的關聯，是定義字體的主體命令。該命令定義了字族下的不同變體。該命令同時具有完全展開版的 `\edefinefontsynonym`。
- `\definetypeface` 定義字體樣式和字體實體之間的關聯，是定義字體的主體命令。該命令定義了字族。

一個簡單地示例如下：

```
\starttypescriptcollection[MyTypescript]
  \starttypescript[serif][MyTypescriptOne]
    \definefontsynonym[Serif][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SerifBold][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SerifItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SerifBoldItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
  \stoptypescript
  \starttypescript[sans][MyTypescriptOne]
    \definefontsynonym[Sans][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SansBold][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SansItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SansBoldItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
  \stoptypescript
  \starttypescript[serif][MyTypescriptTwo]
  \stoptypescript
  \starttypescript[sans][MyTypescriptTwo]
  \stoptypescript
  \starttypescript [MyTypescriptOne]
    \definetypeface [MyTypescriptOne] [rm] [serif] [MyTypescriptOne]
    \definetypeface [MyTypescriptOne] [ss] [sans]  [MyTypescriptOne]
  \stoptypescript
  \starttypescript [MyTypescriptTwo]
    \definetypeface [MyTypescriptTwo] [rm] [serif] [MyTypescriptTwo]
    \definetypeface [MyTypescriptTwo] [ss] [sans]  [MyTypescriptTwo]
  \stoptypescript
\stoptypescriptcollection
```

但這樣書寫實在過於麻煩，尤其是一套字體擁有多種變體。為多套字體編寫時，這樣編寫的工作量會驟增。因此，有幾個便攜的命令可以讓我們從繁瑣的編寫中解放出來。關鍵命令為：

- `\definetypescriptprefix` 定義一些快捷前綴
- `\typescriptprefix` 調用定義好的快捷前綴
- `\typescriptone`  
- `\typescripttwo`
- `\typescriptthree`

`\starttypescript` 可以有三個參數，這三個參數分別可以使用 `\typescriptone`, `\typescripttwo` , `\typescriptthree` 來快捷調用。一個簡單的示例如下：

```
%% 命令的定義如下，可以幫助理解其用法
\permanent\tolerant\protected\def\definetypescriptprefix[#name]#spacer[#prefix]%
  {\gdefcsname\??typescriptprefix#name\endcsname{#prefix}} % made global

\permanent\def\typescriptprefix#name%
  {\ifcsname\??typescriptprefix#name\endcsname\lastnamedcs\else#name\fi}
```

```
%% 假設我們的字體名稱分別是：
%% serif -- YourFontNameSerifRegular
%% serif -- YourFontNameSerifBold
%% serif -- YourFontNameSerifItalic
%% serif -- YourFontNameSerifBoldItalic
%% sans 字體的名稱也類似。

\starttypescriptcollection[MyTypescript]
  \definetypescriptprefix [n:MyTypescriptOne] [YourFontName]
%% \typescriptprefix\typescriptone 會被替換為 第一參數中的 serif 或者 sans
%% \typescripttwo 會被替換為 MyTypescriptOne，因此 \typescriptprefix{n:\typescripttwo} 就會被替換為 n:MyTypescriptOne
  
  \starttypescript[serif,sans][MyTypescriptOne]
    \definefontsynonym[\typescriptprefix\typescriptone]
                      [name:\typescriptprefix{n:\typescripttwo}Regular]
                      [features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[\typescriptprefix\typescriptone Bold]
                      [name:\typescriptprefix{n:\typescripttwo}Bold]
                      [features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[\typescriptprefix\typescriptone Italic]
                      [name:\typescriptprefix{n:\typescripttwo}Italic]
                      [features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[\typescriptprefix\typescriptone BoldItalic]
                      [name:\typescriptprefix{n:\typescripttwo}BoldItalic]
                      [features={some font features},fallbacks=fallbackserif]
  \stoptypescript
  
  \starttypescript[serif,sans][MyTypescriptTwo]
  \stoptypescript
  
  \starttypescript [MyTypescriptOne,MyTypescriptTwo]
    \definetypeface [\typescriptone] [rm] [serif] [\typescriptone]
    \definetypeface [\typescriptone] [ss] [sans]  [\typescriptone]
  \stoptypescript
\stoptypescriptcollection
```

在同一文件內使用打字稿所導致的多餘空格

[![](https://i.sstatic.net/eJ5ZC.png)](https://i.sstatic.net/eJ5ZC.png)

When you write typescripts for a new font ConTeXt stores these settings but no fonts are loaded at this point, this allows complicated typescript defintions where the upright, italic. etc styles can be changed when the fonts are loaded which is usefull for large font families.

Once you create a typeface with the `\definetypeface` commands ConTeXt loads all the necessary typescripts which can be a problem when you do this within regular text, because many line ends in typescripts blocks produce extra spaces with appear now in the output.

In the example below I create a simple typescript for the `TeX Gyre Pagella` font. The problem is that I load the font in a `\hbox` which flushes all spaces from my typescripts in horizontal mode.

```
\starttypescript [serif] [tex-gyre-pagella]
    \definefontsynonym [Serif]           [file:texgyrepagellaregular]    [features=default]
    \definefontsynonym [SerifItalic]     [file:texgyrepagellaitalic]     [features=default]
    \definefontsynonym [SerifBold]       [file:texgyrepagellabold]       [features=default]
    \definefontsynonym [SerifBoldItalic] [file:texgyrepagellabolditalic] [features=default]
\stoptypescript

\starttypescript [tgy]
    \definetypeface [tgy] [rm] [serif] [tex-gyre-pagella]
\stoptypescript

\starttext

\ruledhbox{\strut\space}

\ruledhbox{\strut\space\switchtobodyfont[tgy]}

\ruledhbox{\strut\space\ntimes{\kern\spaceamount}{5}}

\stoptext
```

Each linebreak in my typescript at the end of the `\definefontsynonym` settings creates a visible space and a additional space is created from the `\definetypeface` setting.

[![enter image description here](https://i.sstatic.net/FCkSz.png)](https://i.sstatic.net/FCkSz.png)

To avoid this problem you can drop the `typescript` environment for the `\definetypeface`commands which loads all necessary typescript before you load the fonts, e.g.

```
\definetypeface [tgy] [rm] [serif] [tex-gyre-pagella]
```

or you preload the typescript you want to use before you load it in your document, e.g.

```
\usetypescript[tgy]
```
