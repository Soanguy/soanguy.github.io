## 使用 TeX

### 定义计数器

```
\count0=1\relax %% 定义 0 号计数器为 1
\the\count0 %% 将会得到数字 1

\count2=400\relax  %% 定义 2 号计数器为 1
\the\count2 %% 将会得到数字 400
```

```
\newcount\c_tempa
\c_tempa=1\relax  %% 定义 \c_tempa 为 1
\the\c_tempa %% 将会获得数字 1

\newcount\c_tempb
\c_tempb=400\relax %% 定义 \c_tempb 为 1
\the\c_tempb %% 将会获得数字 400
```

### 计算计数器

```
\newcount\c_tempc\c_tempc=200\relax
\newcount\c_tempd\c_tempd=330\relax
\newcount\c_tempe

\c_tempe=\numexpr\c_tempc + \c_tempd\relax %% 将会计算数字 200+300
\the\c_tempe %% 将会得到数字 530

\the\numexpr\c_tempc + \c_tempd\relax %% 将会得到数字 530
```

### 增减计数器

```
\newcount\c_tempf %未定义，\c_tempf = 0
\advance\c_tempf by 1\relax % 为计数器加 1
\the\c_tempf % 显示该计数器结果 0+1 = 1

\advance\c_tempf by -2\relax % 为计数器加 -2
\the\c_tempf % 显示该计数器结果 1-2 = -1

\multiply\c_tempf by -2\relax % 为计数器乘以 -2
\divide\c_tempf by 2\relax % 为计数器除以 2
```

### 判断计数器

```
\newcount\c_tempg\c_tempg=22\relax
% \newcount\c_tempg\c_tempg=-2\relax

\ifnum\c_tempg > 1\relax
   current c_tempg is \the\c_tempg
\else%
   \advance\c_tempg by 20\relax
   current c_tempg is \the\c_tempg
\fi
```

> [!warning] 
> 数字之后务必使用 `\relax` 来完结。否则，会导致未知错误。特别是在计算数字时。

## ConTeXt 

ConTeXt 定义和使用计数器的方式主要依靠：

- `\definecounter` 定义和设置计数器
- `\setupcounter` 设置计数器
- `\setcounter` 赋值计数器
- `\resetcouter` 重置计数器至初始状态（受 start 影响）
- `\incrementcounter` 计数器数值 +1
- `\decrementcounter` 计数器数值 -1
- `\rawcountervalue` 获得计数器数值
- `\savecounter` 保存当前计数器数值
- `\restorecounter` 恢复被保存的计数器数值
- `\firstcountervalue`
- `\lastcountervalue`
- `\prevcountervalue`
- `\nextcountervalue`
- `\convertedcounter`

### 定义、赋值、测试

```
\definecounter[usercountera]%% 约等同于 \newcounter\usercountera
\setcounter[usercountera][1]%% 约等同于 \usercountera=1\relax
\incrementcounter[usercountera]
\decrementcounter[usercountera]
\rawcountervalue[usercountera]

\ifnum\rawcountervalue[usercountera] = 20\relax
  usercountera equals 20
\else
  usercountera equals \rawcountervalue[usercountera]
\fi
```

### 绑定两个计数器

```
\definecounter[countera]% 定义 countera
\definecounter[counterb][countera]% counterb 绑定 countera
\setcounter[countera][20]
\setcounter[counterb][2]

\incrementcounter[countera]% 增加 counterb
\rawcountervalue[counterb]% countera = 2+1 =3
```
