## 背景

文源（WenYuan）Serif / Sans / Rounded 是覆盖极全的可变字体，单文件动辄几万汉字（BMP、Ext A～I、CJK 兼容区全在）。用 ConTeXt 排版简体中文时，每次编译都要加载这一大坨字形，编译速度明显变慢。

解决思路：按《通用规范汉字表》把字体拆成互不重叠的两个子集，日常排版只用其中的简体子集。

| 子集 | 文件名 | 内容 |
|------|--------|------|
| 简体集 | `*-SC.otf` | 规范表 8105 字 + 附属字符 + 补充字 |
| 扩展集 | `*-EXT.otf` | Ext A～I、兼容汉字、强制扩展字 |

拆分由 `split_wenyuan.py` 完成，ConTeXt 一侧只需一份对应的 typescript。

## split_wenyuan.py 用法

**准备文件**（与脚本同目录）：

- `通用規範漢字表.txt`（必需，8105 字表）
- `简体补充.txt`（可选，强制归入 `-SC`）
- `简体排除.txt`（可选，强制归入 `-EXT`）

字符清单每行可写一个或多个字，支持 `U+4E00` / `0x4E00` 码位，`#` 开头为注释。

**改两处路径**：

```python
BASE = os.path.dirname(HERE)   # 源字体所在目录，如 fonts/Variable_CJK
JOBS = [
    ("WenYuanSerifSCVF.otf",    "WenYuanSerifSCVF",    "WenYuan Serif SC VF"),
    ("WenYuanSansSCFlexVF.otf", "WenYuanSansSCFlexVF", "WenYuan Sans SC Flex VF"),
    ("WenYuanRoundedSCVF.otf",  "WenYuanRoundedSCVF",  "WenYuan Rounded SC VF"),
]
```

**运行**：

```bash
pip install fonttools
python3 split_wenyuan.py              # 同时生成 -SC 与 -EXT
python3 split_wenyuan.py --no-ext     # 只要 -SC
python3 split_wenyuan.py --only-ext   # 只要 -EXT
```

脚本会输出每个字体的统计（简体数 / 扩展数 / 补充命中数），生成 `*-SC.otf` / `*-EXT.otf` 并重写 `name` 表，保证两套可同时安装。

## 注意事项

1. **PS 名 = typescript 前缀**。脚本内部用 `psbase + "-SubsetSC"` 生成 PostScript 名，ConTeXt 规范化后就是 `wenyuanserifscvfsubsetsc`。改 `psbase` 或 `-SubsetSC` 后缀，typescript 里的 `n:` 前缀必须同步改。
2. **换字体后强制刷新缓存**：
   ```bash
   mtxrun --script fonts --reload --force
   mtxrun --generate
   ```
3. **`-SC` 和 `-EXT` 不要硬塞进同一个字体类**。两套字符刻意不重叠，要合排得靠 fallback 链或显式切换字体。
4. **斜体是合成的**（`italic` 特征叠在手写体上），中文没有真斜体；正式出版物需目检。
5. **`mono` / `handwriting` 槽借用了圆体**，因为文源没有专门的等宽/手写家族。有更合适的字体改开头两行前缀即可。
6. **fallback setup 是外部依赖**。`\s!fallbacks=fallback-seriflight` 这类引用需要项目里已有对应定义，否则会警告（不影响基本排版）。

## split_wenyuan.py 

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
文源 (WenYuan) 可变字体子集化脚本
================================================

把 WenYuan Serif / Sans / Rounded 三个可变字体, 各自拆分成两套互不重叠的子集:

  - 简体集 (-SC)  : 《通用规范汉字表》8105 字 + 全部附属字符
                    + 简体补充文件中的字符
  - 扩展集 (-EXT) : 字体其余全部字符 (不在规范表的统一表意文字, 含 Ext A~I,
                    以及全部 CJK 兼容汉字 + 强制扩展文件中的字符)

优先级 (从高到低):
  1. EXTRA_SC_FILES  列出的字符 -> 强制归简体集
  2. EXTRA_EXT_FILES 列出的字符 -> 强制归扩展集
     (若同一字符同时出现在两者中, 简体补充优先)
  3. CJK 兼容汉字 -> 扩展集
  4. 非表意附属字符 -> 简体集
  5. 表意文字 -> 规范表收录则简体集, 否则扩展集

用法:
  python3 split_wenyuan.py              # 默认: 同时生成 -SC 与 -EXT
  python3 split_wenyuan.py --no-ext     # 只生成 -SC
  python3 split_wenyuan.py --only-ext   # 只生成 -EXT

依赖:  fonttools >= 4.0     (pip install fonttools)
"""
import argparse
import os
from fontTools import subset
from fontTools.ttLib import TTFont

HERE = os.path.dirname(os.path.abspath(__file__))
BASE = os.path.dirname(HERE)                 # fonts/Variable_CJK
OUT = HERE                                   # 输出目录 = 本脚本所在目录
SPEC_FILE = os.path.join(HERE, "通用規範漢字表.txt")

# 简体集补充文件: 其中列出的字符会被强制归入 -SC, 优先级最高。
# 可写多个文件, 按顺序读取并合并。文件不存在时自动跳过。
EXTRA_SC_FILES = [
    "简体补充.txt",
]

# 强制扩展文件: 其中列出的字符会被强制归入 -EXT, 即使它本来会被默认规则放进 -SC。
# 与 EXTRA_SC_FILES 冲突时, EXTRA_SC_FILES 优先。
EXTRA_EXT_FILES = [
    "简体排除.txt",
]

# 需要处理的字体: (源文件名, 输出文件名前缀, 家族名)
JOBS = [
    ("WenYuanSerifSCVF.otf",   "WenYuanSerifSCVF",   "WenYuan Serif SC VF"),
    ("WenYuanSansSCFlexVF.otf", "WenYuanSansSCFlexVF", "WenYuan Sans SC Flex VF"),
    ("WenYuanRoundedSCVF.otf", "WenYuanRoundedSCVF", "WenYuan Rounded SC VF"),
]

# CJK 统一表意文字区块: 这些字符按「是否被规范表收录」决定归属
UNIFIED = [
    (0x3400, 0x4DBF),      # Ext A
    (0x4E00, 0x9FFF),      # BMP 统一表意
    (0x20000, 0x2A6DF),    # Ext B
    (0x2A700, 0x2B73F),    # Ext C
    (0x2B740, 0x2B81F),    # Ext D
    (0x2B820, 0x2CEAF),    # Ext E
    (0x2CEB0, 0x2EBEF),    # Ext F
    (0x2EBF0, 0x2EE5F),    # Ext I
    (0x30000, 0x3134F),    # Ext G
    (0x31350, 0x323AF),    # Ext H
]
# CJK 兼容汉字: 默认归入扩展集 (主要面向旧编码/Big5/KS/JIS 等兼容场景)
COMPAT = [(0xF900, 0xFAFF), (0x2F800, 0x2FA1F)]


def in_range(cp, ranges):
    return any(a <= cp <= b for a, b in ranges)


def load_charset(path):
    """读取字符清单文件。

    格式:
      - 每行可写一个或多个字符, 空白分隔
      - 也支持 U+4E00 / 0x4E00 形式的码位
      - 空行和 # 开头的行忽略
    """
    chars = set()
    if not os.path.exists(path):
        return chars
    for line in open(path, encoding="utf-8"):
        line = line.strip()
        if not line or line.startswith("#"):
            continue
        for token in line.split():
            t = token.upper()
            if t.startswith("U+"):
                try:
                    chars.add(int(t[2:], 16))
                except ValueError:
                    pass
                continue
            if t.startswith("0X"):
                try:
                    chars.add(int(t[2:], 16))
                except ValueError:
                    pass
                continue
            for ch in token:
                chars.add(ord(ch))
    return chars


def load_spec(path):
    """读取《通用规范汉字表》, 复用 load_charset 的解析规则。"""
    return load_charset(path)


def build_sets(src, spec, extra_sc, extra_ext):
    """按规则把字体字符集分成 (简体集, 扩展集, 补充命中集, 强制扩展命中集)。"""
    font = TTFont(src, lazy=True)
    all_cps = set(font.getBestCmap().keys())
    font.close()

    extra_hit = extra_sc & all_cps
    force_ext = (extra_ext - extra_sc) & all_cps

    simp = set()
    for cp in all_cps:
        if cp in extra_hit:
            simp.add(cp)
            continue
        if cp in force_ext:
            continue
        if in_range(cp, COMPAT):
            continue
        if (not in_range(cp, UNIFIED)) or (cp in spec):
            simp.add(cp)

    ext = all_cps - simp
    return simp, ext, extra_hit, force_ext & ext


def rename(font, family, ps):
    """重写 name 表, 使两套子集可同时安装而不冲突。"""
    nt = font["name"]
    combos = sorted({(r.platformID, r.platEncID, r.langID) for r in nt.names})
    for pid, eid, lid in combos:
        try:
            nt.setName(family, 1, pid, eid, lid)
            nt.setName("Regular", 2, pid, eid, lid)
            nt.setName(ps + ";subset", 3, pid, eid, lid)
            nt.setName(family, 4, pid, eid, lid)
            nt.setName(ps, 6, pid, eid, lid)
        except Exception:
            pass


def subset_one(src, out, chars, family, ps):
    font = TTFont(src)
    opts = subset.Options()
    opts.layout_features = ["*"]
    opts.name_IDs = ["*"]
    opts.name_languages = ["*"]
    opts.name_legacy = True
    opts.notdef_outline = True
    opts.recommended_glyphs = True
    opts.hinting = True

    sub = subset.Subsetter(options=opts)
    sub.populate(text="".join(chr(c) for c in chars))
    sub.subset(font)
    rename(font, family, ps)
    font.save(out)
    font.close()


def load_extra_list(files, label):
    """读取一组补充文件并合并, 返回字符集合。"""
    chars = set()
    for name in files:
        path = os.path.join(HERE, name)
        if not os.path.exists(path):
            print(f"{label}文件 {name}: 不存在, 跳过")
            continue
        before = len(chars)
        chars |= load_charset(path)
        print(f"{label}文件 {name}: 读取 {len(chars) - before} 个新字符")
    return chars


def parse_args():
    p = argparse.ArgumentParser(description="文源可变字体子集化")
    g = p.add_mutually_exclusive_group()
    g.add_argument("--no-ext", action="store_true", help="不生成 -EXT 子集")
    g.add_argument("--only-ext", action="store_true", help="只生成 -EXT 子集, 不生成 -SC")
    return p.parse_args()


def main():
    args = parse_args()
    gen_sc = not args.only_ext
    gen_ext = not args.no_ext

    spec = load_spec(SPEC_FILE)
    extra_sc = load_extra_list(EXTRA_SC_FILES, "简体补充")
    extra_ext = load_extra_list(EXTRA_EXT_FILES, "简体排除")

    conflict = extra_sc & extra_ext
    if conflict:
        print(f"注意: {len(conflict)} 个字符同时出现在补充与排除文件中, "
              f"按优先级归入 -SC")

    print("《通用规范汉字表》字数:", len(spec))
    print("生成模式:", ("SC" if gen_sc else "") + (" + EXT" if gen_ext else ""))
    os.makedirs(OUT, exist_ok=True)

    for src_name, psbase, fam in JOBS:
        src = os.path.join(BASE, src_name)
        simp, ext, extra_hit, force_ext_hit = build_sets(src, spec, extra_sc, extra_ext)
        print(f"{src_name}: 简体={len(simp)}  扩展={len(ext)}  "
              f"补充命中={len(extra_hit)}  强制扩展命中={len(force_ext_hit)}")

        if gen_sc:
            subset_one(src, os.path.join(OUT, psbase + "-SC.otf"), sorted(simp),
                       fam + " Subset SC", psbase + "-SubsetSC")
        if gen_ext:
            subset_one(src, os.path.join(OUT, psbase + "-EXT.otf"), sorted(ext),
                       fam + " Subset EXT", psbase + "-SubsetEXT")

    print("完成 ->", OUT)


if __name__ == "__main__":
    main()
```


## typescript

把下面内容存成 `type-imp-wenyuan.mkiv`，`\environment` 引入即可。只保留了 `wenyuanhansvf`（完整 VF）和 `wenyuanhanslite`（-SC 子集）两个家族，其余无关前缀、字体全部剔除。

```tex
\starttypescriptcollection[wenyuan]

  % 可变字重轴
  \definefontfeature [wght-250] [axis={wght=250}]
  \definefontfeature [wght-300] [axis={wght=300}]
  \definefontfeature [wght-400] [axis={wght=400}]
  \definefontfeature [wght-500] [axis={wght=500}]
  \definefontfeature [wght-700] [axis={wght=700}]
  \definefontfeature [wght-900] [axis={wght=900}]

  % 完整可变字体
  \definetypescriptprefix [n:wenyuanhansvfserif] [wenyuanserifscvf]%
  \definetypescriptprefix [n:wenyuanhansvfsans]  [wenyuansansscflexvf]%
  \definetypescriptprefix [n:wenyuanhansvfmono]  [wenyuanroundedscvf]%
  \definetypescriptprefix [n:wenyuanhansvfhandw] [wenyuanroundedscvf]%

  % -SC 子集（split_wenyuan.py 产物）
  \definetypescriptprefix [n:wenyuanhansliteserif] [wenyuanserifscvfsubsetsc]%
  \definetypescriptprefix [n:wenyuanhanslitesans]  [wenyuansansscflexvfsubsetsc]%
  \definetypescriptprefix [n:wenyuanhanslitemono]  [wenyuanroundedscvfsubsetsc]%
  \definetypescriptprefix [n:wenyuanhanslitehandw] [wenyuanroundedscvfsubsetsc]%

  % 语言标签（可选；原文件对 wenyuan 未定义，展开为空）
  % \definetypescriptprefix [f:wenyuanhansvf]   [simplified-chinese]

    \edefinefontsynonym [\typescriptprefix\typescriptone ExtraLight]      [\s!name:\typescriptprefix{n:\typescripttwo\typescriptone}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-250},\s!fallbacks=fallback-\typescriptone extralight]

    \edefinefontsynonym [\typescriptprefix\typescriptone Italic]          [HandwritingItalic]                                         [\s!features={\typescriptprefix{f:\typescripttwo}, wght-400,italic},\s!fallbacks=fallback-\typescriptone italic]
    \edefinefontsynonym [\typescriptprefix\typescriptone Medium]          [\s!name:\typescriptprefix{n:\typescripttwo\typescriptone}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-500},\s!fallbacks=fallback-\typescriptone medium]
    \edefinefontsynonym [\typescriptprefix\typescriptone MediumItalic]    [HandwritingMediumItalic]                                   [\s!features={\typescriptprefix{f:\typescripttwo}, wght-500,italic},\s!fallbacks=fallback-\typescriptone mediumitalic]

    \edefinefontsynonym [HandwritingItalic]           [\s!name:\typescriptprefix{n:\typescripttwo handw}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-400,italic},\s!fallbacks=fallback-handwitalic]

    \edefinefontsynonym [HandwritingHeavyItalic]      [\s!name:\typescriptprefix{n:\typescripttwo handw}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-900,italic},\s!fallbacks=fallback-handwheavyitalic]
    \edefinefontsynonym [HandwritingSlanted]          [\s!name:\typescriptprefix{n:\typescripttwo handw}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-400, slanted},\s!fallbacks=fallback-handwslanted]
    \edefinefontsynonym [HandwritingBoldSlanted]      [\s!name:\typescriptprefix{n:\typescripttwo handw}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-700, slanted},\s!fallbacks=fallback-handwboldslanted]
    \edefinefontsynonym [HandwritingCaps]             [\s!name:\typescriptprefix{n:\typescripttwo handw}] [\s!features={\typescriptprefix{f:\typescripttwo}, wght-400},\s!fallbacks=fallback-handwcaps]

  \starttypescript [wenyuanhansvf, wenyuanhanslite]
    \definetypeface [\typescriptone] [\s!rm] [\s!serif]       [\typescriptone] [\s!default]
    \definetypeface [\typescriptone] [\s!ss] [\s!sans]        [\typescriptone] [\s!default]
    \definetypeface [\typescriptone] [\s!hw] [\s!handwriting] [\typescriptone] [\s!default]
    \definetypeface [\typescriptone] [\s!tt] [\s!mono]        [\typescriptone] [\s!default]
    \definetypeface [\typescriptone] [\s!mm] [\s!math]        [pagella]        [\s!default]
  \stoptypescript

\stoptypescriptcollection
```

引入后即可直接用两个家族名：

```tex
% 日常简体排版：用 -SC 子集，编译最快
\setupbodyfont [wenyuanhanslite, 12pt]

% 需要全字符覆盖时切换
\setupbodyfont [wenyuanhansvf, 12pt]
```

局部切字体：

```tex
{\switchtobodyfont[wenyuanhansvf] 龘}
```

如果要同时用 `-EXT` 子集，参照上面两组前缀再加一份 `wenyuanhansext*`，并把它补进两段 `\starttypescript` 的家族列表即可。
