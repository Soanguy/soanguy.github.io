## 建立自定义的打字稿

不同于通过 `\definefont` , `\definedfont` , `\definefontfamily` 等可以直接在当前文稿中定义或直接使用的字体命令，还可以通过在外部文件中定义字体，并在文稿中通过 `\usetypescript` 等命令来调用相关的字体。

要使用 typescriptfile 来定义字体主要依赖以下命令：

| 命令                           | 说明                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------ |
| `\usetypesctipt`             | 调用打字稿中定义好的字体                                                                   |
| `\usetypescriptfile`         | 调用外部文件打字稿中定义好的字体                                                               |
| `\loadtypescriptfile`        | 加载外部文件打字稿中定义好的字体                                                               |
| `\starttypescriptcollection` | 一系列相关的 typescript 合集可以用该命令包裹                                                   |
| `\starttypescript`           | 开始定义 typescript                                                                |
| `\definefontsynonym`         | 定义字体样式和字体实体之间的关联，是定义字体的主体命令。该命令定义了字族下的不同变体。该命令同时具有完全展开版的 `\edefinefontsynonym` |
| `\definetypeface`            | 定义字体样式和字体实体之间的关联，是定义字体的主体命令。该命令定义了字族                                           |

一个简单地示例如下：

```
\starttypescriptcollection[MyTypescript]
  \starttypescript[serif][MyTypescriptOne]
    \definefontsynonym[Serif][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SerifBold][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SerifItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SerifBoldItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
  \stoptypescript
  \starttypescript[sans][MyTypescriptOne]
    \definefontsynonym[Sans][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SansBold][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SansItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
    \definefontsynonym[SansBoldItalic][name:YourFontName][features={some font features},fallbacks=fallbackserif]
  \stoptypescript
  \starttypescript [MyTypescriptOne]
    \definetypeface [MyTypescriptOne] [rm] [serif] [MyTypescriptOne]
    \definetypeface [MyTypescriptOne] [ss] [sans]  [MyTypescriptOne]
  \stoptypescript
\stoptypescriptcollection
```

## 自动载入 typescriptfile

用户自定义的 typescript 想要激活的话，需要通过

```
\usetypescriptfile[your typescript file name]
\setupbodyfont[font name you want]
```

但是，每次都需要显示指定需要载入的 typescriptfile 过于麻烦。ConTeXt 设定了 `\definefilesynonym` 命令来快速的链接 typesctiptfile 和 fontname。
例如，我们在 `type-imp-source` 中设定了 sourcehansc、sourcehantc、sourcehanjp 等一系列的 typesctipt 。那么，我们可以

```
\definefilesynonym [type-imp-sourcesc.mkiv] [type-imp-source.mkiv]
\definefilesynonym [type-imp-sourcetc.mkiv] [type-imp-source.mkiv]
\definefilesynonym [type-imp-sourcejp.mkiv] [type-imp-source.mkiv]
```

这样，就可以直接使用 `\setupbodyfont[sourcesc]` 来直接激活该打字稿，无须通过 `\usetypescriptfile` 显示指定。

## 杂项

### 打字稿定义中文字体时无法正常匹配字体

目前似乎 ConTeXt 对于字体的查找识别时，只能够正常识别含有英数等符号名称的字体文件。如果文件名称中含有汉字字符时，会导致字体识别出现问题（乱码）。

一个解决办法就是修改字体文件名称，使其仅含有 英数 符号。

```
方正仿宋.ttf --> FZfangsong.ttf
```
