## 盒子基础

盒子（Box）是 TeX 中的基本对象，用于包含文本、图形等内容。

### 创建盒子

```
\newbox\mybox
\setbox\mybox=\hbox{内容}
\box\mybox
```

### 盒子类型

- `\hbox` - 水平盒子
- `\vbox` - 垂直盒子
- `\vtop` - 顶部对齐的垂直盒子

## 盒子操作

### 获取盒子尺寸

```
\wd\mybox  % 宽度
\ht\mybox  % 高度
\dp\mybox  % 深度
```

### 复制盒子

```
\copy\mybox  % 复制并保留原盒子
\unhbox\mybox  % 解包水平盒子
\unvbox\mybox  % 解包垂直盒子
```
