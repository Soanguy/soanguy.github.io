## 判断两个命令是否相等

## 判断命令是否已存在

```
\ifdefined\Command do something\else do anothor\fi
\ifcsname Command\endcsnam do something\else do anothor\fi
\expandafter\ifx\csname Command\endcsnam do something\else do anothor\fi
```

## 判斷參數，讓命令自適應參數內容

```
\ifhastok={#2} do something\else do anothor\fi% 如果 #2 是 key=value 形式
```
