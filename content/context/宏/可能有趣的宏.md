## 处理逗号列表

```
%https://tex.stackexchange.com/questions/159118/how-to-iterate-over-a-comma-separated-list?noredirect=1

\def\apply#1#2{\applyA#1#2,\applyA,}
\def\applyA#1#2,{\ifx\applyA#2\empty\else #1{#2}\afterfi{\applyA#1}\fi}
\def\afterfi#1#2\fi{\fi#1}% #2 似乎没有必要

%test:
\def\p#1{(#1)}
\apply\p{1,2,3}  % expands to (1)(2)(3)
```

`\apply\p 1,2,3` 会扩展成 `\applyA\p 1,2,3,\applyA,`
进一步扩展会进行条件判断，如果 \applyA 和 #2 相同则终止处理。
否则，循环执行如下内容（`\else` 之后的内容）
`\applyA\p 1,\afterfi{\applyA#1}\fi`。
同时，`\afterfi` 会被扩展为 `\fi\applyA\p`，
从而提前终止当前条件，并再次执行 `\applyA\p 2,3,\applyA,`。
如此循环，直到遇到 `\applyA`，则终止全部。

## 模擬 ConTeXt labeltext 分割前後標籤

在 ConTeXt 中，可以通过 `setuplabeltext[chapter={第，章}]` 来为标题添加前后标签。达到 「第 XX 章」的效果。

```text
\def\xxx#1#2{%
  \expandafter\edef%
    \csname p_current#1#2label%
      \expandafter\expandafter%
        \expandafter\endcsname%
          \expandafter\expandafter%
            \expandafter{% #1parameter 是 ConTeXt 命令
              \csname #1parameter\endcsname{#2label}}}% 獲取由 #1parameter{#2label} 所定義的標籤

\def\p_pass_currentlabel[#1]{\p_assign_currentlabel[#1,,]}
\def\p_assign_currentlabel[#1,#2,#3]#4%
 {\expandafter\def\csname  left_assigned#4label\endcsname {#1}%
  \expandafter\def\csname right_assigned#4label\endcsname {#2}}% 定義前後標籤

  \expandafter\expandafter%
    \expandafter\p_pass_currentlabel%
      \expandafter\expandafter%
        \expandafter[%
            \csname p_current#1#2label\endcsname]{#2}% 獲取由逗號分隔的前後標籤
%%% \csname left_assigned#4label\endcsname {#1} 可以獲取前標籤
%%% \csname right_assigned#4label\endcsname {#2}可以獲取後標籤

例如：\xxx{question}{point} ==> 獲取由 \setupquestion[pointlabel={,points}] 的前後標籤，即 "points"。
```

\def\testwords#1{
   \begingroup

   \expandafter\endgroup

\def\readwords#1 #2\relax{
     \doword{#1}% #1 = substr, #2 = rest of string
     \begingroup
     \ifx\relax#2\relax%  is #2 empty?
        \def\next{\endgroup\endtestwords}%your own end-macro if required
     \else
        \def\next{\endgroup\readwords#2\relax}
     \fi
     \next}
\def\doword#1{(#1)}
\def\endtestwords{}
\testwords{Now good enough} %Gives `(Now)(good)(enough)`
